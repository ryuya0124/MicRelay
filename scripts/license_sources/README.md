# License source provenance

`bundler-LICENSE.md` is copied verbatim from `LICENSE.md` in the official `bundler-4.0.24.gem` distribution:

https://rubygems.org/downloads/bundler-4.0.24.gem

The system Ruby installation omits Bundler's top-level license file. Remaining package and vendored-component notices are read from exact installed versions resolved by Gemfile.lock.

Regenerate with `bundle exec ruby scripts/generate_licenses.rb`.
