# レイテンシーの比較

2026-11-15、iPad Pro 13 M4、本体マイク → FIIO KA13、48 kHz。EQ ON、ゲームなし。

変更前の同条件でユーザーが外部測定した総遅延は約47 ms。ビルド5で再測定した結果として、ユーザーから **11.7〜12 ms** の報告を受けた。約35.0〜35.3 ms、約74.5〜75.1%の短縮に相当する。

再測定時は本体マイク → KA13、保存済みEQ ON、自動選択の標準モード。ゲイン・上限・EQ設定の保持は端末から前後比較して確認した。総遅延の値はユーザーによる外部計測の報告で、測定波形や詳細な計測手順は取得していない。以下のOS報告値やコールバック時間とは測定対象が異なり、他の端末・機器・条件に共通する値ではない。

## バッファ要求と実値

`setPreferredIOBufferDuration` の成功だけでは、希望する実バッファになったと判断できない。256フレームで稼働した後に1・2・4・8フレームを要求すると、希望値の取得結果は小さくなっても、実値は256フレームのままだった。一方、16フレームを明示的に要求すると実値も16になった。

|要求|実コールバック|実I/O時間|
|---:|---:|---:|
|2 / 4 / 8 frames|256 frames|5.333 ms|
|16 frames|16 frames|0.333 ms|
|32 frames|32 frames|0.667 ms|
|64 frames|64 frames|1.333 ms|
|256 frames|256 frames|5.333 ms|

開始時の探索は各候補でセッションを再構成し、起動直後の安定待ちを経て、実コールバックと処理フレーム数を確認する。観測時間の80%以上を処理し、欠落・入力取得エラーがない候補を比較する。要求どおりのサイズで安定すると、そのモードでの探索を終える。小さい候補が不安定なら512・1024・2048フレームまで試す。端末名による固定値は使わない。

## 音声モード

|モード|入力のOS報告値|出力のOS報告値|実コールバック|
|---|---:|---:|---:|
|標準|1.292 ms|0.292 ms|16 frames / 0.333 ms|
|測定|0.292 ms|16.792 ms|16 frames / 0.333 ms|

この接続では標準を選ぶ方が入出力の合計は短かった。測定モードが常に最短とは限らない。96 kHzの希望値は採用されず、実値は48 kHzだった。`mixWithOthers` を外した比較でも、最小の実コールバックは16フレームで変わらなかった。通常動作ではゲームと同時再生するため混在を維持する。

これらの値を足した数字は、マイクから耳までの実測値ではない。USB機器、変換処理、安全バッファなどの遅延を外部測定で別途確認する必要がある。

ビルド5でも同じiPad＋KA13＋本体マイク＋保存済みEQ ONで16フレームを確認。起動後の66秒間に3,135,664フレームを処理し、追加欠落0・音声エラー0だった。ゲイン・上限・EQ設定は変更前と一致した。I/Oバッファ0.333 msと、ユーザーが外部再測定した総遅延11.7〜12 msは別の値として扱う。

## EQ

EQは6段のIIR biquadを同じRemoteIOコールバック内で処理する。先読みや追加の再生バッファはない。OFFはハードバイパス。約5 msの係数補間は操作時の変化をなめらかにするためのもので、音声を5 ms貯める処理ではない。

ただしIIRには周波数ごとに異なる位相変化と群遅延がある。保存されていた設定のローパス（362 Hz、Q = 4.667850610678599、他の5段は0 dBのピークで非稼働）について、実装と同じ定常係数の位相応答を微分すると次の値になる。

|周波数|群遅延の計算値|
|---:|---:|
|100 Hz|0.118 ms|
|200 Hz|0.247 ms|
|300 Hz|1.225 ms|
|362 Hz|4.106 ms|
|500 Hz|0.300 ms|

これは音全体を一定時間ずらす遅延とは異なり、設定と周波数に依存する。Qを大きくしたフィルターは周辺帯域で響きが残り、外部測定の波形の形やピーク位置にも影響し得る。CPUの処理所要時間、I/Oバッファ時間、群遅延、外部で測った総遅延は区別する。

### CPU処理コストの補助測定

iPhone 17実機で、実装の `processEqualizer` を最適化ありのObjective-C++から呼び出す補助測定を行った。48万サンプルを処理する8回の試行のうち初回を除き、1サンプルあたりの時間の中央値を16サンプルに換算した。

|処理|16サンプルあたりの換算時間|
|---|---:|
|OFF（バイパス）|0.014 µs|
|上記設定、1段稼働|0.098 µs|
|6段すべて稼働|0.117 µs|

音声割り込み内の最大実行時間やiPadの測定値ではない。OSのスケジューリング、入力取得、出力コピー、解析データ転送なども含まない。まとまったサンプルを処理した計算コストの目安であり、この数値を音響遅延の実測値として扱わない。非公開の記録は `artifacts/iPhone17-EQTiming.xcresult`。

参考：[Apple: Audio Session Preferred Values](https://developer.apple.com/library/archive/qa/qa1631/_index.html)、[MathWorks: Group Delay and Phase Delay](https://www.mathworks.com/help/signal/ug/delay.html)。
