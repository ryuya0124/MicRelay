# プライバシーポリシー

更新日：2026年11月15日

MicRelay（開発者：ryuya）は、マイク音声を同じ端末の出力先へ返すアプリです。

- マイク音声・波形・周波数解析は端末内で処理します。音声ファイルの録音・保存、開発者のサーバーへの送信は行いません。
- アカウント、広告、トラッキング、アクセス解析、第三者の分析SDKは使用しません。開発者はアプリから利用者のデータを収集しません。
- ゲイン、ゲイン上限、EQ、バックグラウンド動作の設定は端末内に保存します。アプリを削除すると、OSの管理に従って削除されます。
- マイク権限はモニターに必要です。権限はOSの「設定」で取り消せます。
- デバッグ版のみ、開発検証用にレイテンシーやフレーム数などの数値診断を端末内に保存します。音声は含みません。App Store向けRelease版では保存しません。
- GitHubなどの外部リンクを開くと、リンク先サービスのプライバシーポリシーが適用されます。お問い合わせ時に利用者が送信した情報は、対応のために扱います。

お問い合わせ：[GitHub Issues](https://github.com/ryuya0124/MicRelay/issues)。公開の場に音声・個人情報・認証情報を投稿しないでください。
