# プライバシーポリシー

[English](en/PRIVACY.md)

更新日：2026年11月16日

MicRelay（開発者：ryuya）は、マイク音声を同じ端末の出力先へ返すアプリです。

- マイク音声・波形・周波数解析は端末内で処理します。モニターのみでは音声ファイルを保存しません。開発者のサーバーへ音声・動画を送信しません。
- iOS／iPadOS 27以降の画面録画機能は、利用者が開始し、OSの画面選択を完了した場合だけ画面とアプリ音声を動画として端末内に保存します。モニター音の除外は初期ONで、OFFの場合はモニター音も動画に含まれます。録画用マイク・カメラの収録は行いません。保存した動画は利用者の操作で共有・書き出しできます。共有先には共有先の規約・プライバシーポリシーが適用されます。
- 録画した動画を写真アプリへ保存するため、写真ライブラリへの追加だけを許可する権限を要求します。既存の写真・動画を閲覧する権限は要求しません。写真へ保存した動画はOSの写真・iCloud設定に従って管理されます。保存成功後はアプリ内のコピーを自動削除します。許可されない場合や保存に失敗した場合は、動画をアプリ内に残して再保存・共有・手動削除を選べます。アプリ内の削除操作では、写真アプリの動画を削除しません。
- アカウント、広告、トラッキング、アクセス解析、第三者の分析SDKは使用しません。開発者はアプリから利用者のデータを収集しません。
- ゲイン、ゲイン上限、EQ、バックグラウンド動作、録画の音声除外などの設定と、利用者が録画した動画は端末内に保存します。アプリを削除すると、OSの管理に従って削除されます。
- マイク権限はモニターに必要です。権限はOSの「設定」で取り消せます。
- デバッグ版のみ、開発検証用にレイテンシーやフレーム数などの数値診断を端末内に保存します。音声は含みません。App Store向けRelease版では保存しません。
- GitHubなどの外部リンクを開くと、リンク先サービスのプライバシーポリシーが適用されます。お問い合わせ時に利用者が送信した情報は、対応のために扱います。

お問い合わせ：[GitHub Issues](https://github.com/ryuya0124/MicRelay/issues)。公開の場に音声・個人情報・認証情報を投稿しないでください。
