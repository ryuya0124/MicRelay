# MicRelay サポート

[English](en/SUPPORT.md)

[使い方](../README.md) / [プライバシーポリシー](PRIVACY.md) / [ライセンス](../THIRD_PARTY_NOTICES.md)

1. イヤホンまたはHDMI機器を接続し「接続とマイクを更新」でマイクを許可します。
2. 入力マイクを選択します。USB・Bluetoothなどでは接続先がイヤホンであることを確認します。
3. モニターを開始します。ゲインは端末のシステム音量とは別です。
4. イコライザー画面では音声を聞きながら入力と処理後のスペクトラムを確認できます。バンドストップは指定した下限〜上限を減衰し、バンドパスはその範囲だけを通します。OFF時はEQ処理をバイパスします。

音が出ない場合は、マイク権限、選択した入力、接続先の確認、ゲインとシステム音量を確認してください。別アプリがマイクを使用している場合は中断することがあります。Bluetoothの遅延は機器と通信方式に依存します。

不具合・ご要望は [GitHub Issues](https://github.com/ryuya0124/MicRelay/issues) へ、機種・OS・接続機器・再現手順を添えてお知らせください。音声、個人情報、認証情報の添付は不要です。

「風切り音低減」は音量と音質の欄でON/OFFできます。低域カット周波数を上げるほど低い風音を減らしますが、声の低音も減ります。EQとは独立して動作し、設定のバックアップにも含まれます。

音声モードは通常「自動」を使ってください。「完全手動」ではフレーム数とサンプルレートをドロップダウンで選び、「確認して適用」で無音の確認を行います。要求どおりに動作した場合だけ保存されます。適用できなければ理由と実値を表示し、前の設定に戻します。モニター中は要求値と現在の実値を並べて確認できます。機器や接続条件が変わり、保存した手動設定を使えなくなった場合は停止するため、自動に切り替えるか手動設定を変更してください。
