# EQ・風切り音低減・タップ音ゲート

EQは6バンド。増減・ノッチ・ローカット・ハイカットに加え、バンドストップは指定範囲を減衰し、バンドパスは指定範囲を通す。例えば下限500 Hz・上限2,000 Hzなら、その範囲を削る／通す選択になる。下限と上限は20〜20,000 Hz、間隔は1 Hz以上。グラフで境界をドラッグするか数値・スライダーで調整する。

範囲フィルターは1段のbiquadで、両端は約−3 dBの境界。垂直に完全遮断するフィルターではなく、端から離れるほど減衰する。上限が実サンプルレートのナイキスト周波数以上の場合は、表現可能な下限のローカット／ハイカットへ変換する。範囲全体が表現できない高域ならバンドパスは無音、バンドストップは通過となる。

風切り音低減はEQから独立した4次Butterworthハイパス（2段のbiquad）。初期状態はOFF、カット周波数は120 Hzで、60〜600 Hzに調整できる。低域の風音を減らすが、声や音楽の低域も削られる。広帯域の風音やマイクが飽和した歪みの完全除去はできない。OSの声の分離やVoiceProcessingIOを有効にする機能ではない。

信号の順序は入力→風切り音低減→EQ→タップ音ゲート→ゲイン→クリップ→出力。各OFFは独立したハードバイパスで、該当するフィルターや検出器の状態を読み進めない。スペクトラムは未処理の入力と、風切り音低減・EQ・タップ音ゲートの処理後、ゲイン前を比較する。FFTは解析専用で、再生は解析を待たない。

どちらの処理も同じRemoteIOコールバック内でサンプルごとに処理し、先読み・追加の再生キューを持たない。約5 msの係数補間は操作の変化をなめらかにする時間で、音声を貯める時間ではない。ただしIIRの群遅延は周波数・設定に依存するため、追加バッファがないことと音響的に遅れがないことは異なる。[遅延の記録](LATENCY.md)も参照。

既存EQの種類番号・周波数・Q・増減・ゲインは維持。従来の保存データに範囲の境界がない場合だけ初期値を補い、元のフィルターは変えない。現在のバックアップは形式4で、形式1〜3も読み込める。旧形式にない機能はOFFで復元する。

## タップ音ゲート（ビルド10）

イコライザー画面に独立したON/OFFを用意。初期OFF・通過時間12 ms、最小入力−42 dBFS、背景音との差16 dB。時間は1〜1,000 msの数値・スライダー、レベルは−90〜0 dBFS、差は3〜30 dBで調整する。通過中も検出器を動かし、次の立ち上がりを検出すれば、その時点から指定時間へ更新する。前の通過時間が終わるまで連打を無視する固定待機時間はない。画面にはモニター中の開閉と検出回数も表示する。

「検出に使う音」でフィルター前の元のマイク音／EQ・風切り音低減の後の音を切り替える。初期値はフィルター後。ハイカットやバンドパス等との併用時に、不要帯域も含めて立ち上がりを検出するか、絞った音だけで検出するかを選べる。どちらでも実際に通す音には有効なEQ・風切り音低減が適用される。切り替えはサンプルを参照し分けるだけで、Audio Unitの再構成・先読み・別の解析キューを使わない。検出元の変更時には、以前の音のレベルを新しい音と比較しないよう背景推定と通過窓を初期化する。

検出サンプルの瞬時パワーが絶対レベルと背景音に対する比率の両方を満たした時、そのサンプル位置から処理済みの音を出力する。先読み・FFT・フレーム蓄積・アタック用の待ち時間はない。背景音は20 ms時定数で追従するが、これは音を20 ms貯める処理ではない。短い強音で背景推定が急増しないよう更新を制限し、連打自体を背景音とみなしてしまうことを抑える。再検出はピークが約6 dB低下するか、背景に対するヒステリシス条件を満たした後に許可する。0.4 msのピーク減衰は再検出の判定用で、最初の音を遅らせない。

通過時間は検出サンプルを含めて数え、末尾最大0.2 msをその時間内で減衰して切る。クリック抑制のための短いフェードで、通過時間を延長したり音声を遅らせたりしない。小さい立ち上がりはしきい値に達するまで欠ける。OFF時は入力値と状態を変えず返す。係数計算・設定受け渡しは音声サンプル処理の外で行い、コールバックは待機・ロック・動的確保をしない。

タップの意味を識別する機能ではない。他の急な音にも反応し、開いている間は背景音も一緒に通る。重なって明確な落ち込みがない音の分離や、あらゆる連打の検出は保証しない。開始直後で背景音の推定がまだないときにも反応する場合がある。拾えない場合は最小レベルや差を下げ、雑音にも反応する場合は上げる。時間を短くすると余韻・背景音の通過は減るが、タップ音の末尾も切れる。

8〜384 kHzで、しきい値を超えた最初のサンプルの出力、持続音の時間切断、連続背景音とタップ、2 ms間隔の100回連打、ブロックサイズによらない出力一致、OFFの完全不変をテストした。連打は合成信号による検証で、実機のタップ検出率や音響総遅延の測定ではない。

ハイカット／バンドパスでしきい値未満まで小さくした実フィルター出力に対して、前の音なら検出し、後の音なら検出しない条件も確認。前を選んだ場合もフィルター前の音を出力へ混ぜず、最初の処理済みサンプルをそのまま通す。EQの増幅後だけしきい値を超える逆の条件、検出元の保存・バックアップ往復と未保存時の初期値もテストしている。
