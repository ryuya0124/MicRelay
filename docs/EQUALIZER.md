# EQと風切り音低減

EQは6バンド。増減・ノッチ・ローカット・ハイカットに加え、バンドストップは指定範囲を減衰し、バンドパスは指定範囲を通す。例えば下限500 Hz・上限2,000 Hzなら、その範囲を削る／通す選択になる。下限と上限は20〜20,000 Hz、間隔は1 Hz以上。グラフで境界をドラッグするか数値・スライダーで調整する。

範囲フィルターは1段のbiquadで、両端は約−3 dBの境界。垂直に完全遮断するフィルターではなく、端から離れるほど減衰する。上限が実サンプルレートのナイキスト周波数以上の場合は、表現可能な下限のローカット／ハイカットへ変換する。範囲全体が表現できない高域ならバンドパスは無音、バンドストップは通過となる。

風切り音低減はEQから独立した4次Butterworthハイパス（2段のbiquad）。初期状態はOFF、カット周波数は120 Hzで、60〜600 Hzに調整できる。低域の風音を減らすが、声や音楽の低域も削られる。広帯域の風音やマイクが飽和した歪みの完全除去はできない。OSの声の分離やVoiceProcessingIOを有効にする機能ではない。

信号の順序は入力→風切り音低減→EQ→ゲイン→クリップ→出力。各OFFは独立したハードバイパスで、該当するフィルターの状態を読み進めない。スペクトラムは未処理の入力と、風切り音低減・EQの処理後、ゲイン前を比較する。FFTは解析専用で、再生は解析を待たない。

どちらの処理も同じRemoteIOコールバック内でサンプルごとに処理し、先読み・追加の再生キューを持たない。約5 msの係数補間は操作の変化をなめらかにする時間で、音声を貯める時間ではない。ただしIIRの群遅延は周波数・設定に依存するため、追加バッファがないことと音響的に遅れがないことは異なる。[遅延の記録](LATENCY.md)も参照。

既存EQの種類番号・周波数・Q・増減・ゲインは維持。従来の保存データに範囲の境界がない場合だけ初期値を補い、元のフィルターは変えない。新しいバックアップは形式2で風切り音低減も保存し、形式1も読み込める。旧バックアップには風切り音低減がないためOFFで復元する。

DSP実装は本プロジェクトのMITソース。式の参考：[W3C Audio EQ Cookbook](https://www.w3.org/TR/audio-eq-cookbook/)。低域カットによる風音低減の例：[Shure MV88ガイド](https://www.shure.com/en-US/docs/guide/MV88)。追加の実行時依存ライブラリはない。
